# quant-lab 백테스트 대시보드

한국 대형주 모멘텀 · 미국 레버리지(TQQQ) 전략의 백테스트 결과를 인터랙티브하게 탐색하는 정적 대시보드.

- **보기**: GitHub Pages 로 배포된 `index.html` 접속 (예: `https://<user>.github.io/quant-lab-results/`)
- **기능**: 전략 다중 선택, 기간 프리셋/커스텀, 로그/선형 축, 수익곡선·낙폭·연도별 수익률, 성과 지표표

## 해석 주의

- 선택 **구간** 지표는 전체 백테스트 NAV 를 그 시점 기준으로 재정규화해 계산한 "뷰"이며, 그 시점부터
  전략을 새로 돌린 결과가 아닙니다. 비용·세금·신호는 전체기간 가정에 종속됩니다.
- **전체기간** 표 수치는 원 프로젝트의 요약표(CSV)와 동일합니다.
- XIRR·양도세·회전율 등은 전체기간 전용이라 구간을 좁히면 "—" 로 표시됩니다.
- 한국 전략은 KRX 시점별(PIT) 유니버스 미사용으로 **생존편향**이 있을 수 있습니다(과대평가 가능).

> 이 사이트는 quant-lab 저장소에서 자동/수동으로 생성·배포됩니다. 데이터·그래프는 투자 권유가 아니며
> 연구·교육 목적입니다.
