## 왜 만들었나 — 핵심 철학

"이 전략이 시장을 이긴다"를 자랑하는 도구가 아니라, **비용·세금·생존편향까지 정직하게 반영했을 때 단순
매수후보유를 정말로 이기는가**를 검증하는 도구입니다.

- **수익률보다 위험.** 분산배분·추세추종·듀얼모멘텀의 본질적 효익은 대개 "수익률 상승"이 아니라 **낙폭
  (MDD)·변동성 축소**입니다. 강세장만 보면 단일 자산(S&P500·TQQQ)이 raw 수익으로 앞서지만, 위기 구간을
  포함하면 위험조정 성과(Sharpe·MDD)에서 분산·추세 전략의 가치가 드러납니다.
- **"우위 없음"도 결과다.** 예컨대 한국 대형주의 "종목 선정형" 가격 모멘텀은 학술 연구상 약하거나 오히려
  역전됩니다(Chui·Titman·Wei 2010; Han·Lee·Kang 2020 등). 비용 차감 후 KOSPI200 매수후보유를 못 이기면,
  그 사실 자체가 유효한 학습 결과입니다 — 이 백테스트는 그것을 검증하는 귀무가설 도구입니다.
- **정직한 데이터 표기.** 한국 종목 백테스트는 시점정합(PIT) 유니버스를 무료로 복원할 수 없어 **생존편향**이
  들어갑니다(아래 [해석 주의](#해석-주의-정직성-노트) 참고). 사이트는 이를 숨기지 않고 경고로 표시합니다.
- **재현성 vs 최신성.** 로컬은 고정 종료일로 재현 가능하게, 공개본은 **굴러가는 종료일**(`--end 오늘`)로
  항상 최신까지 계산합니다.
- **공정 비교.** 일시불(매수후보유)과 점진투입(DCA)은 투입구조가 달라 평가액 직접비교가 무의미하므로,
  **위험은 TWR(시간가중)·수익은 XIRR(금액가중)** 으로 분리해 잰다. 모든 신호는 look-ahead(미래참조)를
  구조적으로 차단한다.

### 🇰🇷 한국 대형주 모멘텀
3종 비교 — **v1 종목 선정형**(시총 상위 종목을 12-1개월 모멘텀으로 랭킹해 상위 N 동일가중) · **v2 지수
추세추종**(KODEX 200을 절대모멘텀/200일선/모멘텀스코어로 보유·아니면 현금·채권 헤지) · **v3 듀얼 모멘텀**
(국내·해외·채권 중 상대강세 자산, 절대모멘텀 미달 시 방어). 핵심 질문은 "비용·2026년 매도 거래세(0.20%)를
차감하고도 KOSPI200 매수후보유를 이기는가". **v1은 현재 환경에서 생존편향(FDR 폴백)** 으로 동작하므로 그
우위를 곧이곧대로 믿어선 안 되며, 추세·듀얼(v2·v3)은 지수/ETF 기반이라 이 편향에서 비교적 자유롭다.

### 🇺🇸 미국 레버리지 ETF (TQQQ)
3배 레버리지 ETF에 대한 **라오어 무한매수법(V1 원조·V2 책버전)** 을 일별 주문단위(평단가·LOC 종가체결)로
백테스트하고 DCA·추세추종(LRS)·밸류 리밸런싱·매수후보유와 비교한다. 한국 투자자 관점의 **해외주식 양도세
(22%)·환율(USD/KRW)·미투입 현금 이자**까지 반영. **+ HFEA**(Hedgefundie: 55% UPRO / 45% TMF, 3배 레버리지
위험균형, 분기 리밸)도 합성 UPRO/TMF로 추가 — raw 수익은 최고지만 MDD≈−69%·Sharpe는 무레버리지 1x보다
낮아(레버리지 디케이) "수익보다 위험" 교훈을 단적으로 보여준다. **레짐 편향이 핵심 교훈**: 강세장(2010~)만 보면 TQQQ
매수후보유가 CAGR 40%대로 압도하지만 **MDD ≈ −82%** 이고, 무한매수법 V1은 한국 양도세로 세후 수익이
깎이며 V2는 MDD를 절반 이하로 줄이는 대신 수익도 낮다. 반대로 닷컴·2008을 포함한 합성 구간(1999~)에선
TQQQ 매수후보유가 **MDD ≈ −99.98%로 사실상 전멸**하고 추세추종(LRS)이 그나마 방어한다. 유튜브가 흔히
보여주는 2010+ 구간은 강한 선택편향임을 드러낸다. 합성 TQQQ는 `3·r_QQQ − 차입·보수`로 만들고 실제(2010+)
대조로 검증(일간상관 0.999).

### 🌐 글로벌 자산배분 (정적·동적)
`rebalancer-project`(웹앱)의 정적·동적 자산배분을 Python으로 이식. 둘 다 월별·비중 기반이라 한국 트랙과
**동일한 월별 엔진**을 재사용한다(엔진엔 밴드 트리거만 추가).
- **정적**: 고정비중 10자산(+현금·원자재) + 주기 리밸(월/분기/반기/연) + 표류 밴드 트리거. 프리셋(리밸런서
  기본·균형·주식중심·방어적·올웨더풍·US 60/40 · **영구 포트폴리오**(Harry Browne) · **정통 올웨더**(Dalio)).
- **동적 17종**: BAA(공격/균형) · GEM 듀얼모멘텀 · 추세추종(Faber GTAA) · 절대 듀얼모멘텀 · 한미 6개월
  모멘텀 5종 · Faber GTAA5 · ADM 가속 · VAA-G4 · DAA-G12 · **CDM**(Antonacci 종합 듀얼모멘텀) · **PAA1**(Keller
  보호자산배분) · **Naive Risk Parity**(역변동성) — 모두 월봉 신호로 매월 비중 재산출.
- 자산은 장기 프록시로 스티칭해 **미국 주식·채권/금은 1871년**까지 거슬러 올라가며, **USD 기준 + 원화 환산**
  곡선을 함께 낸다. 교훈: 2008을 포함하면 분산배분의 **낙폭 축소**가 또렷하다(USD MDD가 S&P500의 절반 수준).

### 🪙 암호화폐 (BTC·ETH·XRP)
코인마다 10전략(매수후보유 · DCA 월적립 · 이동평균선 20/60/120/200일 × **달러/원화 신호**). 미국 일별
엔진·DCA 전략을 그대로 재사용. yfinance 일봉(00:00 UTC = 한국 09:00) 기준, 거래수수료 편도 0.1%, 세금 미적용.
변동성이 커 매수후보유 MDD가 −70~−80%에 달하며, 추세 전략의 효익도 주로 낙폭 축소다.

### 🏠 국내 부동산 (아파트 지수)
한국은행 ECOS의 **KB·한국부동산원 월간 지수**로 6종 분석 — **매매 Buy&Hold**(전국·수도권·지방·서울 +
KB 1986~, KOSPI200·금과 한 차트 비교) · **지역별 매매 비교**(17개 시도) · **전세 vs 매매**(자가 매수 vs
전세거주+차액 위험자산 투자) · **갭투자 레버리지**(순자산=집값−초기보증금 → 레버리지 1/(1−전세가율)로 증폭) ·
**갭 × 추세 타이밍**(실거래지수 기준 — 월별 타이밍 신호는 비용 전에도 매수후보유에 미달한다는 진단에서 출발,
전세 무이자 레버리지 + 전환 최소화(히스테리시스·최소보유 24개월)만 비용 차감 후 살아남는다) ·
**지역 모멘텀 로테이션**(시도 12-1 상대모멘텀, 연 1회 리밸). 취득세·중개·보유세를 차감한다. ⚠ 부동산 지수는
평활·지연이 커 변동성·MDD가 과소·Sharpe 과대 추정되므로 주식·금과 위험지표 직접 비교는 주의. 시군구(구·군)
단위 **국토교통부 실거래가** 상세(단지·전용㎡·전세가율 매수타이밍)는 추가 진행 중.

## 분석 & 도구

### 📊 정량분석 — 브라우저에서 즉석 재계산
사전계산 값에 고정되지 않는다. 빌드가 **8자산 월수익 행렬**을 JSON에 동봉하고, `analytics-live.js`가
브라우저에서 직접 계산한다.
- **상관 히트맵** · **효율적 프론티어**(정통 마코위츠 long-only 경계 + 접점(Max Sharpe)·최소분산(GMV) +
  몬테카를로 구름) · **포트폴리오 결과지표**(접점·최소분산·리스크패리티·동일가중의 CAGR/MDD/Sharpe + 성장곡선).
- **기간 조절**: 상단 기간 컨트롤(3·5·10년/시작·종료)을 바꾸면 그 구간의 효율적 전략을 즉석 재계산.
- **전략 탐색기**: 위험성향 슬라이더로 그 위험 수준의 효율적 비중을 산출, 자산 비중을 직접 바꿔 **내
  포트폴리오를 프론티어에 ◇로 찍고 효율 갭**을 표시.
- **분석 자산 선택**: 체크박스 부분집합 + 전통 포트폴리오 유니버스 프리셋(미국 60/40·영구·올웨더·글로벌).
- 평균-분산 추정오차 민감성 때문에 **강건 대안**(최소분산·리스크패리티·동일가중)을 병치하고 **방법론 설명**
  패널을 둔다.

### 🧪 전략 비교 · 플레이그라운드 · 블렌딩
- **전략 비교**: 같은 통화의 전 전략 곡선을 한 차트에 오버레이 + 열 헤더 클릭 정렬 리더보드.
- **플레이그라운드 / 정적 프리셋 즉석 재계산**: 임의 비중 슬라이더 또는 명명 프리셋에서 **리밸런싱 주기
  (없음/월/분기/반기/연)·밴드 ±%** 를 바꾸면 브라우저(`alloc.js` JS 엔진)가 진짜 재백테스트한다. Python
  엔진과 NAV **<1e-6 패리티**를 테스트로 보장. **정적 프리셋엔 리밸런싱 민감도 스윕**(주기×밴드 격자를
  한 번에 재백테스트해 CAGR/MDD/Sharpe 히트맵)도 있다.
- **전략 블렌딩 + 적립식**: 여러 전략을 비중 결합(일시불 또는 주기 리밸런싱)한 곡선·지표 + **월 적립식(XIRR)**.
  선택 전략들의 **상관관계 + 효율적 프론티어**(Max Sharpe·최소분산 GMV·현재 내 블렌드 위치)를 계산하고, 추천 비중을 한 번에 적용.

### 📈 분석 강화 (모든 백테스트 뷰, 브라우저 즉석)
다른 백테스트 툴(PortfolioVisualizer·testfol) 패리티. 이미 받은 NAV로 계산하며 기간 슬라이더에 반응.
- **롤링 수익률**: N년 이동창 CAGR 분포(최저~중앙~최고·양(+)창 비율) — 단일 CAGR이 시작 시점 운에 좌우됨을 정량화.
- **최대 낙폭 Top-5**: 가장 깊은 고점→저점→회복 에피소드(낙폭·회복일·수중 개월).
- **월별 수익률 히트맵**: 연×월 그리드.

### 🧰 도구·지표
- **낙원계산기**: 복리+인플레 → 은퇴 자산·월수입·실질수익률 계산(순수 클라이언트, [keep-ones.me](https://keep-ones.me/#/paradise-calculator2) 참고).
  **+ Monte Carlo 모드**: 매월 수익을 모수(정규)·전략 과거 부트스트랩으로 수천 경로 시뮬 → **자금 생존율(%)**·
  잔액 백분위 팬차트(결정론 단일값 옆에 분포·불확실성 병치).
- **시장 심리**: 공포·탐욕 게이지 바 · VIX · DXY · 금은비 · 김프 등 + 지표별 설명.
- **추세 경보**: 천장(climax-top)·**Stage-2 재진입** 각 6신호 표 + 거장 이론(오닐·미너비니·와인스타인) +
  6신호 임계표 + **시그널 정확도 백테스트**(과거 트리거일 forward return vs 베이스라인).
- **데이터 정확도**: 자산별 신뢰도 등급·실측 범위·프록시 출처(기간별)·CAGR 오차추정·포트폴리오 영향.
- 시장 심리·추세 경보는 **매일 자동 갱신**된다.

## 대시보드 사용법

**2단 네비게이션**: 상단 **영역**(자산배분 / 주식 / 코인 / 부동산 / 도구·지표) → **분류** 탭 → **전략·프리셋** 드롭다운
→ **원화/달러 토글**.

- **자산배분** = 동적 · 정적 · 정량분석 · 전략비교 · 블렌딩
- **주식** = 모멘텀(한국 대형주) · 미국 TQQQ · 미국 지수 모멘텀(QQQ·S&P500) · **적립식 시뮬레이터**(월 적립금·기간·종목을 직접 입력)
- **코인** = BTC/ETH/XRP (매수후보유 · DCA · 이동평균선 · 메이어 멀티플 · 파이 사이클 탑 · 골든크로스 · 현금 리밸런싱)
- **부동산** = 매매 Buy&Hold · 지역별 매매 비교 · 전세 vs 매매 · 갭투자 레버리지 · 지역 모멘텀 로테이션
- **도구·지표** = 낙원계산기 · 시장심리 · 추세경보 · 데이터정확도

공통 기능: 전략 다중선택 · 기간 프리셋/커스텀 · 로그축 · 수익곡선 · 낙폭 · 연도별 수익 · 성과표(정렬 리더보드,
**MDD를 CAGR 옆에**) · 전략 설명 패널(리밸런싱 주기 표기) · **다크모드**(시스템 자동 + 토글) · Pretendard
웹폰트 · **모바일 카드형 표**(좁은 화면에서 가로 스크롤 제거, 전략·자산명이 항상 헤더로 보임).

## 데이터 & 방법론

- **장기 프록시 스티칭**: 실제 ETF는 상장이 늦어, 자산마다 유사 익스포저의 인덱스·공개 시계열을 최신
  세그먼트부터 정의하고 과거를 스케일해 이어붙인다. 미국 주식/채권·금은 **1871년**(Shiller·datahub London
  금가)까지, 인도 1997, 환율 1981, 금 원계열 1833까지. 8자산 통합·정량분석 공통구간은 **1997~**.
- **오프라인 딥히스토리 번들**: FRED 직접 CSV가 막힌 환경/CI에서도 재현되도록 USD/INR·USD/KRW·금 등을
  공개 datahub에서 받아 저장소에 번들로 커밋한다.
- **통화**: 모멘텀 신호는 비율 기반이라 통화 무관 — NAV만 통화별로 환산해 **USD/원화** 곡선을 함께 낸다.
- **비용·세금**: 한국 주식 수수료 0.015%·슬리피지 0.10%(편도)·**매도 거래세 0.20%(2026)**; 미국·코인은
  편도 0.1% 수준 + 미투입 현금 단기금리 이자; 해외주식 **양도세 22%**(연 250만원 공제)와 환율 반영.
  글로벌 ETF는 증권거래세 없음(라운드트립 ≈10bps).
- **look-ahead 차단**: 신호는 그 시점까지의 과거 가격만 사용하고, 수익 실현은 다음 구간에 일어난다 —
  신호 결정과 수익 실현이 겹치지 않도록 엔진·테스트로 보장.

## 해석 주의 (정직성 노트)

- **구간 지표는 "뷰"다.** 기간을 좁히면 전체 백테스트 NAV를 그 시점 기준으로 재정규화해 구간 CAGR/MDD/Sharpe를
  다시 계산한 것이며, **그 시점부터 전략을 새로 돌린 결과가 아니다**. 비용·세금·신호는 전체기간 가정에 종속된다.
- **전체기간 표 = 원 프로젝트 요약표(CSV)와 100% 일치**(엔진 계산값 그대로). 구간 표는 NAV 기반 재계산이라
  일부 지표가 2자리 소수에서 미세하게 다를 수 있다.
- **XIRR·양도세·회전율**은 전체기간 전용 → 구간을 좁히면 "—"로 표시된다.
- **한국 종목 생존편향**: KRX 시점별(PIT) 유니버스 미사용 → "오늘 살아남아 대형주가 된" 종목 위주라 v1
  성과가 **과대평가**될 수 있다(과거 KOSPI200 구성종목 무료 복원 불가). 이 모드에서 v1이 이겨도 모멘텀의
  증거가 아니다.
- **합성·딥히스토리는 근사**: 합성 TQQQ(pre-2010)는 강제 디레버리징·거래상대방 한도를 미반영한 반사실
  모델이고, 프록시 스티칭/딥히스토리(1833~)는 서로 다른 출처를 이어붙인 근사다 — 구간 선택에 민감하다.
- **시장 심리·추세 경보**는 best-effort 수집이라 일부 외부 지표(CNN F&G·일부 김프)는 환경/지역에서 누락될 수 있다.

## 이 사이트는 어떻게 만들어지나 (아키텍처)

**정적-우선 설계**: 계산은 Python으로 **미리** 하고, 그 결과 JSON을 브라우저가 읽어 Plotly로 그린다.
서버가 필요한 건 ①실시간 데이터 ②임의 파라미터 엔진 재실행뿐인데, 후자는 **브라우저 JS가 직접
재계산**(플레이그라운드·정량분석)하므로 서버 없이 충분하다.

```
백테스트(Python, pandas/numpy)
   └─ curves(NAV) + 지표표 + 8자산 월수익 행렬  →  results/**/dashboard_*.json
build_dashboard.py
   └─ web/*(index.html · app.js · alloc.js · analytics-live.js · style.css) + JSON
      → data/manifest.json 생성 + 에셋 캐시버스팅(?v=해시)
GitHub Actions
   ├─ publish-dashboard.yml  (매주 일 21:00 UTC) — 전 백테스트 재계산 → 공개 repo로 push
   └─ daily-signals.yml      (매일 21:00 UTC)   — 시장심리·추세경보 JSON만 교체
GitHub Pages  →  https://skim-log.github.io/quant-lab-results/
```

- **2-저장소 분리**: 코드·파이프라인은 비공개(`skim-log/quant-lab`), 결과 사이트만 공개
  저장소(`skim-log/quant-lab-results`)로 배포한다. 인증은 광범위한 PAT가 아니라 **저장소 전용 배포키
  (SSH deploy key)** 를 쓴다.
- **클라이언트 재계산 패리티**: 브라우저 JS 엔진(`alloc.js`·`analytics-live.js`)은 Python 엔진을 미러링하며,
  NAV·마코위츠 결과가 Python과 일치함을 테스트로 검증한다.
- **로컬 미리보기**: `file://` 직접 열기는 CORS로 실패 → `python -m http.server` 같은 정적 서버가 필요하다.

> **다음 단계**: 연구/실행을 분리한 학습용 파이프라인으로, 백테스터는 "리밸일별 목표 비중"만 출력한다.
> 이후 별도 실행 어댑터(한국투자증권 KIS Developers API, 모의투자부터)로 실전 자동매매에 잇는 것을 염두에 둔다.
