# quant-lab 백테스트 대시보드

한국 모멘텀 · 미국 레버리지(TQQQ) · 글로벌 자산배분(정적·동적) · 암호화폐 백테스트 + 정량분석 · 도구를
인터랙티브하게 탐색하는 정적 대시보드(바닐라 JS + Plotly).

- **보기**: GitHub Pages 배포 (예: `https://skim-log.github.io/quant-lab-results/`)
- **네비**: 2단 대분류 **자산배분 / 개별전략 / 도구·지표** → 소분류 → 전략/프리셋 → 원화·달러 토글.
- **기능**: 전략 다중선택·기간 프리셋/커스텀·로그축·수익곡선·낙폭·연도별·성과표(열 정렬 리더보드·MDD를 CAGR 옆에)·전략 설명 패널.
- **정량분석**(`analytics-live.js`, 브라우저 즉석 재계산): 상관 히트맵 · 효율적 프론티어(**정통 마코위츠**+몬테카를로) ·
  **포트폴리오 결과지표**(접점·최소분산·강건 대안 CAGR/MDD/Sharpe + 성장곡선) · 리스크패리티 · 위험수익 ·
  **기간 조절**(슬라이더로 그 구간 즉석 재계산) · **전략 탐색기**(위험성향 슬라이더로 최적 비중 / 내 비중 점 찍어 효율 갭) ·
  **분석 자산 선택**(체크박스 부분집합 + 전통 포트폴리오 유니버스 프리셋) · **방법론 설명** 패널.
- **도구·지표**: 낙원계산기(은퇴 계산기·천단위 콤마, keep-ones.me 참고) · 시장 심리(공포탐욕 게이지·VIX·DXY·금은비·김프) ·
  추세 경보(천장·**Stage-2 재진입** 각 6신호 + 거장 이론 + **시그널 정확도 백테스트**) · **데이터 정확도**(자산 신뢰도·프록시 출처·오차).
- **UI**: 다크모드(시스템 자동 + 토글)·Pretendard 웹폰트·테마 인식 Plotly · **모바일 카드형 표**(좁은 화면 가로 스크롤 제거).
  시장심리·추세경보는 일일 자동 갱신.

## 해석 주의

- 선택 **구간** 지표는 전체 백테스트 NAV 를 그 시점 기준으로 재정규화해 계산한 "뷰"이며, 그 시점부터
  전략을 새로 돌린 결과가 아닙니다. 비용·세금·신호는 전체기간 가정에 종속됩니다.
- **전체기간** 표 수치는 원 프로젝트의 요약표(CSV)와 동일합니다.
- XIRR·양도세·회전율 등은 전체기간 전용이라 구간을 좁히면 "—" 로 표시됩니다.
- 한국 전략은 KRX 시점별(PIT) 유니버스 미사용으로 **생존편향**이 있을 수 있습니다(과대평가 가능).

> 이 사이트는 quant-lab 저장소에서 자동/수동으로 생성·배포됩니다. 데이터·그래프는 투자 권유가 아니며
> 연구·교육 목적입니다.
